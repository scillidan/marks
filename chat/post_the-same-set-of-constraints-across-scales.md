**《尺度之间的同一组限制——从房间到行星的分级、冗余、分区与接口》**

建筑学常被归入造型问题，但建造首先受一组限制支配。现象学会说，人总以身体进入空间；控制论会说，系统必须预设故障；生态学会说，边界决定什么能够流经。用建筑学的语言概括，这组限制有四项：分级（hierarchy）、冗余（redundancy）、分区（partition）与接口（interface）。它们不决定风格，却决定房间、建筑、街坊、城市、区域与行星能否长期使用。

**分级处理变化中的次序。**高差、距离与速度都不能被一次性越过，而要分成可被逐步确认的阶段。竖向交通拆成踏步与停歇，水平移动拆成路径与节点，设备与管线被置于较低层级，人的活动保持在较高层级。房间遮蔽内部构造，建筑集中竖向通道，街坊以过渡空间区分内外，城市以道路等级分配速度，区域沿分水岭与等高线安排水与路，行星以海拔、昼夜与季节安排光与热。分级的作用不是压低复杂度，而是把复杂度放到后面，让每一阶段只承担可处理的部分。

**冗余处理失效。**任何功能都不能只剩单一路径，因为路径一断，功能即停。有效冗余要求替代路径与原始路径具有不同失效原因：受同一烟气控制的两个出口仍是一个出口，受同一回路控制的两盏灯仍是一盏灯。双通道、备用线路、可绕行道路、错开布置的农田与林地、彼此承接的海洋与大气，共同点不在数量，而在独立。冗余提供的不是重复，而是当一部分失效时，其余部分仍能保持整体可运行。

**分区处理差异。**不同过程具有不同速度、强度与耐受范围，若持续处于同一范围，会相互消耗。分区以边界限制这种消耗，边界可以是墙体、院落、防火分隔、绿带、行政界线、流域界线，也可以是昼夜与季节。分区不等于隔绝，它承认差异必须存在，同时限定差异扩散的范围。房间分隔私密与公共，建筑分隔使用空间与设备空间，街坊划分半公共界面，城市安置不同功能，区域处理上下游与山海关系，行星分开快过程与慢过程。

**接口处理相接。**两个范围相接时，不要求内部一致，只要求接合处有稳定规则。门的尺寸与开启方式、窗台的停留宽度、骑楼的遮蔽深度、桥墩与渡口的位置、岸线、大气与磁场，都属于接口。接口规定进入、停留与离开的方式，并维持相接双方的完整。没有接口，相接会变成混合；接口过强，相接又会消失。接缝问题的实质，是让不同保持不同，同时允许有限的通过。

这些限制不专属于某一个尺度。房间、建筑、街坊、城市、区域与行星并不互相复制外观，它们面对的对象也不同，但都被同一组条件穿过。于是，一个尺度上形成的做法，常在更大尺度上改换材料重新出现：门、墙与院落处理相接和分隔；道路、绿带与河流处理更大范围的分隔和流经；昼夜、海拔与海陆分布则把同样的关系推到行星表面。所谓同构，不在形状，而在尺度更换之后，这组限制仍然有效，仍然要求建造给出回答。

限制被放进构造之后，日常使用很少把它当作知识。人通过门、上下楼层、穿过街巷、接近水面时，判断已经由尺寸、坡度、边界与接缝提前完成；只有限制失效或被移除时，它才会重新变得可见。由此看，这组限制并不是建筑学额外加给世界的解释，而是建造能够把经验固定在物中的原因；经验一旦固定，陌生环境才可能被直接理解。
